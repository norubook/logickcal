# ロジッカルのロジカルな部分

- ゆるふわな感じに破壊表現を加えたい．
- 実用性はそこまでなくても良い．
- 不特定な部分でエルフィンがいたずらすると面白い

- 変数が信用できないようにする？
- 変数から自動生成される裏変数みたいなのを実装させるのが面白そう．


# 開発予定

- 裏変数面白そう
- いたずら機能欲しい
