# ロジッカルのロジカルな部分

- ゆるふわな感じに破壊表現を加えたい．
- 実用性はそこまでなくても良い．
- 不特定な部分でエルフィンがいたずらすると面白い

- 変数が信用できないようにする？
- 変数から自動生成される裏変数みたいなのを実装させるのが面白そう．


# 開発予定

- 裏変数面白そう
- いたずら機能欲しい
- ビジュアル化でほっぺを何らかしらで実装させたい．

# 動作仕様

- yaccとlexを使用してコンパイラを作成する
- logickcalで作成されたファイルのみを用いるのではなく，総合フォルダにまとめて使徒データなどを格納するようにする(他のプログラミング言語でのimportファイルの一部を適宜書き換えられるようにする．)(データの保存方法をどんな形式にするかは未定(JSON?))


# 使用方法

### プログラムを書く場合

- プログラムは使徒定義部と動作関数部に分かれる
- 使徒定義部では使徒の各設定を定義する
- 動作関数部は複数の関数からなる．書き方は基本的にC言語ベースである．



### プログラムをコンパイルする場合

- exeファイルを使用してください．

```
./sample.exe < program.loal > output.py

```




### プログラムを使用する場合

- main.py(?)プログラムを起動しファイルを選択して実行を行ってください．
